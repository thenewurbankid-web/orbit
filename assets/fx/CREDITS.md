# Effect imagery

Real photos and footage, offline renders and CC0 models used for Orbit's light, fire, craft, vessels and frame. Each file has a full-size
version (desktop) and a `-sm` version (phones and the low tier). All were re-encoded without metadata
(JPEG via Pillow, WebP with no EXIF/XMP). Licences were checked on each file's Wikimedia Commons page
(`extmetadata` LicenseShortName) or on ambientCG, on 2026-10-04 (aurora, lightning, comet and meteor added the same day).

Usage: `realfx.js` (blast flipbook, blaster bolts and hit sparks, beams, ship models, meteor trail, comet body), `flares.js` (CSS lens flares: glint, flare, streak), `fleet.js` (vessels, plasma cores), `planetfx.js` (impacts, beacon, clear sky, supply, attack,
aurora curtain, storm lightning), `scene.js` (question streak, ship fire, UFO beam, meteors, comets, warp streaks, far-nebula lightning), `frame.js` (steel), `intro.js` (flare, glint, streak in the white-out).
